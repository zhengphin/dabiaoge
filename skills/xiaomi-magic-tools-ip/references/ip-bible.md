# IP 圣经：小米的奇妙办法局

## 1. 一句话定位

一个总想用捷径绕过成长的小女孩，每次向神秘又不太靠谱的表哥借来一件临时神奇工具，却在笑闹失控后发现：真正能改变生活的，是她最后那一步不靠工具的选择。

## 2. 类型、受众与世界观

- 类型：家庭向日常奇幻、角色喜剧、轻成长单元剧。
- 核心受众：7–14 岁儿童及共同观看的家长；成年人能从拖延、讨好、怕失败等处获得二次共鸣。
- 基本舞台：一座熟悉、温暖、略显拥挤的当代华人社区“慢半拍街”。家、学校、便利店、楼道、小公园、菜市场和表哥的阁楼工坊彼此步行可达。
- 奇幻规则：神奇工具确实有效，但只改写信息、感受、概率、时间感或局部现实，不能永久改变人格、制造真爱、抹掉责任、复活生命或无代价控制他人。
- 社会规则：多数成年人只把异常当巧合；孩子与少数家人可能看见结果。工具造成的物理与关系后果不会因工具消失而自动归零。
- 来源留白：表哥把这些东西称为“办法零件”。不急于解释完整宇宙起源，长期只以标签、旧订单、失败原型等碎片扩展谜团。

本 IP 的辨识度来自“熟悉烦恼 + 歪聪明需求 + 冷面表哥 + 精准但有缝隙的工具 + 自己迈出的最后一步”，而不是某一件道具。

## 3. 小米角色圣经

### 核心定义

小米是一个脑子转得快、心比嘴软、总想少走一步却常常多绕十圈的孩子。她不是道德范本，也不是被动受教者；她会犯观众犯过的错，并能在后果最难堪时做出一点点更勇敢的选择。

### 性格与能力

- 好奇、机灵、联想跳跃，擅长从规则中找“漏洞”。
- 冲动，先行动后补理由；对新办法的兴奋往往压过风险判断。
- 嘴硬心软，有同理心，但在害怕丢脸时会先保护自己。
- 善于观察小细节，却常把零散事实拼成一个很离谱的结论。
- 恢复力强：可以沮丧、嘴硬、逃跑，但不会长期自怜。

### 优点

- 真诚、有行动力、能承认“我其实是害怕”。
- 对朋友与家人有保护欲。
- 面对新鲜事物没有成年人的成见。
- 失败后能创造性补救，不只是口头认错。

### 缺点

- 追求即时回报，容易拖延、讨好、嫉妒、逞强和甩锅。
- 把“能做到”误当成“应该做”。
- 习惯把复杂情绪包装成一个可被工具解决的技术问题。
- 一次成功后迅速膨胀，喜欢私自扩大使用范围。

### 欲望与恐惧

- 表层欲望：轻松一点、体面一点、立刻被喜欢、马上知道答案。
- 深层欲望：被看见、被接纳，同时保有自主权。
- 核心恐惧：犯错后不再被喜欢；认真尝试后仍失败；承认需要别人。

### 说话与思考方式

- 先把麻烦说小：“就一点点”“我只是想确认一下”。
- 把不合理要求包装成严谨方案，语速越快越心虚。
- 爱用字面逻辑和自造术语，结论常差半步。
- 被戳中时先反驳，停半拍，再小声承认关键事实。
- 禁止固定口头禅；保持节奏和逻辑习惯即可。

### 情绪与喜剧特征

- 情绪来得快、藏不住，脸上比嘴上早一步承认事实。
- 她会认真执行一个荒谬计划，越严谨越好笑。
- 喜剧来自自信与现实的落差、偷换概念、过度优化、越补救越糟。
- 笑点要允许观众笑她的选择，不嘲笑她的外貌、能力或脆弱。

### 习惯与价值观

- 遇事先找捷径，再在途中收集证据证明捷径合理。
- 会给计划列出看似专业但优先级颠倒的步骤。
- 价值底线是“不想真的伤害人”；一旦看见具体伤害，她会动摇并补救。
- 她相信办法很多，但逐渐学会有些事只能亲自面对。

### 成长方式

每集只长一小格：从逃避到开口、从控制到倾听、从求完美到完成、从讨好到表达真实需求。她下一集仍可能犯相似类型的错，但原因、情境和选择必须不同。成长不是永久升级，而是经验沉淀：后续可用一句犹豫、一次更早的停手体现她记得。

### 视觉识别

保持清晰、灵活的轮廓：略前倾、蓄势要跑的重心；大而灵活的眼神与会泄密的眉形；身上有一处高饱和暖色，搭配便于行动的日常服装与可变化的小配件。视觉资产若已由项目参考图确立，以参考图为准，但手中不得永久绑定遥控器或任何工具。

即使没有神奇工具，观众仍应从“歪聪明的方案—兴奋执行—被现实戳破—嘴硬半拍—主动补救”认出她。

## 4. 表哥角色圣经

### 核心定义

表哥是一个冷面、懒散、脑洞精确却人生经验并不完整的年轻发明家。他提供的不是答案，而是一块会把问题照大的试纸。

### 性格、优点与缺点

- 淡定、低能耗、观察敏锐，吐槽短而准。
- 尊重小米的主体性，不抢结论，也不把她当笨孩子。
- 喜欢验证工具和人性假设，偶尔把生活当实验。
- 说明书写得过度技术化，或故意省略“不危险但很麻烦”的副作用。
- 高估自己的预测，低估情感变量；自己的工具也会用错。
- 怕麻烦，却会在真正危险时立刻介入。

### 与小米的关系

他是哥哥、发明家、吐槽役和半吊子人生导师的混合体。表面是小米求他，实际上他需要小米提醒自己：人不是参数。两人有信任，也会互相利用——小米想要捷径，表哥想看测试结果；底层始终是家人式兜底。

### 喜剧功能

- 用冷反应对撞小米的高能量。
- 一本正经地给荒谬工具取朴素或过度精确的名字。
- 在关键时刻补充限定条件：“我以为你会看第十七页。”
- 偶尔成为副作用的第一受害者，打破导师权威。
- 禁止固定吃饭、固定拿碗、固定抬眼等机械记忆点。

### 故事功能

- 追问小米“你究竟想让什么消失”，帮助显露表层需求。
- 给出规则明确但不完美的工具。
- 中段不立刻救场，只给最少提示，让小米承担选择。
- 高潮时守住安全边界，但不替小米道歉、坦白或完成关系修复。
- 尾声允许他也被小米反将一军，使关系平等。

### 视觉识别

与小米形成体块和节奏反差：稳、圆、低重心，轮廓简洁；大镜片或其他“观察者”视觉元素可保留；服装偏冷中性色、实用、略居家。双手与场景道具应随剧情变化，不绑定饭碗、筷子或遥控器。

## 5. 小米 × 表哥关系引擎

### 对话模式

1. 小米把真实问题包装成“纯技术咨询”。
2. 表哥用一个过于准确的问题戳破包装。
3. 小米否认并提出狭窄需求。
4. 表哥照字面满足，让需求本身暴露荒谬。

示例节奏：

- 小米：“有没有一种，不算撒谎但能让真话晚点到的东西？”
- 表哥：“有。叫闭嘴。”
- 小米：“要能说话的版本。”

不要复用示例措辞；复用“绕着说—直刺—再加条件”的关系节奏。

### 冲突模式

- 小米认为表哥没说明白；表哥认为小米只听了想听的部分。
- 小米要求收回后果；表哥能关掉工具，却不能收回别人已经感受到的事。
- 表哥把问题当机制，小米把问题当关系；结尾两人各修正一半。

### 搞笑模式

- 高能量计划 vs 低能量吐槽。
- 小米钻规则漏洞，表哥指出漏洞其实是正门。
- 表哥预测三种事故，偏偏发生第四种。
- 两人短暂结盟掩盖小事故，马上因不同策略把它扩大。

### 情绪模式

表哥很少直接安慰，而是留在场、递回选择或承认自己的责任。小米很少长篇感谢，而是用补救行动或一句别扭的话表达信任。真正的柔软只停留一两拍，随后用轻笑点收束。

### 长期发展

- 前期：交易型——“给我工具 / 让我测试”。
- 中期：协作型——小米开始追问规则，表哥开始说明风险。
- 后期：互助型——小米能识别表哥在逃避的情绪，表哥也愿意承认“不知道”。
- 关系升级不可抹去基本喜剧反差；亲近意味着更敢指出彼此的问题，不是变得永不冲突。

## 6. 固定冲突与角色禁区

长期固定的是：捷径欲望与真实成长的冲突、控制欲与关系不可控的冲突、技术逻辑与情感逻辑的冲突。

不得固定：每集动作、口头禅、出场姿势、表情、手持物、同一工具、同一颜色特效、同一音效、同一追逐、同一爆炸、同一反转、同一道德结论。

不得把小米写成纯熊孩子、永远正确的乖孩子或只会触发事故的按钮；不得把表哥写成全知圣人、恶意实验者或随叫随到的售货机。
