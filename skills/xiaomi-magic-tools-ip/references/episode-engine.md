# 1–3 分钟单集引擎与 Master Prompt

## 1. 标准结构

时长可按平台调整；重点是因果节拍，不是机械卡秒。

| 时段 | 叙事任务 | 编剧检查 |
|---|---|---|
| 0–5 秒 | Hook：问题以最尴尬、最奇怪或最危险的一刻先出现 | 即使静音也能看懂“哪里不对”吗？ |
| 5–20 秒 | 回到问题起点；建立小米的表层目标与真实压力 | 问题是否具体到今天必须处理？ |
| 20–35 秒 | 小米去找表哥，把情感问题包装成技术需求 | 对话是否体现二人的节奏反差？ |
| 35–50 秒 | 工具亮相；一句功能、一条关键规则、一个视觉示范 | 说明是否短到不拖戏？限制是否埋下伏笔？ |
| 50–70 秒 | 第一次使用成功，小米得到明确甜头 | 观众是否能理解她为何继续用？ |
| 70–105 秒 | 2–4 个连续笑点，范围、关系和代价逐级升级 | 每拍是否改变局面，而非重复同一笑话？ |
| 105–135 秒 | 工具失控或被小米的选择推到极端，问题扩大 | 失控是否源自已展示的规则？ |
| 135–160 秒 | 高潮：表面捷径失效，小米必须在丢脸与负责之间选择 | 她是否亲自完成关键行动？ |
| 160–175 秒 | 情感转折：关系得到部分修复，结果不必完美 | 对方是否保有自己的反应和选择？ |
| 175–180 秒 | 回扣式尾梗或温柔余味 | 删除解释意义的台词后仍成立吗？ |

1 分钟版压缩为 8 拍：Hook、问题、求助、工具、成功、两拍升级、失控与选择、尾梗。3 分钟版可给配角一拍反应，但不可增加无关支线。

## 2. 单集开发卡

- 现实问题：
- 小米今天想要：
- 她不愿承认自己害怕：
- 她的错误办法：
- 表哥为何愿意给工具：
- 工具一句话功能：
- 工具规则与禁止事项：
- 第一次甜头：
- 喜剧升级 1（私人）：
- 喜剧升级 2（关系）：
- 喜剧升级 3（公共/不可逆）：
- 失控触发：
- 小米不靠工具做的关键行动：
- 她付出的轻微代价：
- 关系如何变化：
- 无说教结尾画面/尾梗：

## 3. 笑点升级原则

- 同一规则，不同后果：不要只是“更多、更大、更吵”。
- 每一拍都让小米获得新信息并做出更糟但可理解的选择。
- 配角不是笑点机关；他们有各自目标，会误解、拒绝、反击或意外受益。
- 高潮前至少让小米有一次停手机会；她主动继续，责任才成立。
- 尾梗可让工具残留一个小后果、表哥被反噬或小米把教训理解得“差一点”，但不能否定刚发生的成长。

## 4. 意义如何自然产生

不要写“今天我学到了……”。让意义由三个可见动作构成：

1. 前段小米逃避某动作，如道歉、等待、询问、承认不知道。
2. 工具把逃避的成本放大。
3. 高潮她主动完成那个动作，即使结果未必如愿。

结论应具体、有限、与当集行为绑定。例如“道歉不保证被原谅，但承认错误是自己的责任”，优于“做人要诚实”。

## 5. 角色与故事设计禁区

- 不固定每集同一工具、动作、道具、口头禅、转场或视觉特效。
- 不为“记忆点”强行重复 gimmick；记忆来自决策逻辑与关系节奏。
- 不让工具一次解决核心问题，也不让表哥代替小米完成成长。
- 不把副作用写成与主题无关的随机故障。
- 不靠工具突然坏掉、梦醒了、全员失忆或回到原点抹除后果。
- 不每集都用公开道歉、朋友原谅、拥抱、表哥总结作为结局。
- 不把配角变成只负责夸奖、原谅或惩罚小米的功能人。
- 不重复“第一次成功—复制越来越多—爆炸”这一单一升级模型。
- 不照搬任何现有动画的角色外形、台词、道具设计或经典桥段。
- 不牺牲儿童安全常识：危险模仿行为需被阻断，不能以成功结果奖励。

## 6. 100 集长期运营框架

### 建立四张轮换表

1. 问题域：自我管理、家庭、友谊、学校、社区、数字生活、消费与物品、身体感受、规则与公平、想象与未来。
2. 深层恐惧：不被喜欢、失败、落后、失控、被误解、无聊、错过、承担责任、与众不同、让人失望。
3. 工具机制：信息、时间、情绪、概率、表达、交换、过滤、放大、自动化、局部改写。
4. 结尾动作：坦白、等待、拒绝、倾听、归还、重做、求助、补偿、分享、接受未知。

相邻集不要在四张表中重复超过一项。每 10 集审查一次主题、工具载体、笑点结构和结尾动作。

### 分层连续性

- A 层（每集可看）：独立问题完整收束。
- B 层（10 集可感）：小米更早察觉自己的老毛病；表哥更愿意说明限制。
- C 层（季度彩蛋）：工坊来源、失败原型、家族往事只推进一点，不绑架单集。

### 变化与恒定

恒定：人物欲望、缺点、价值底线、关系节奏、工具的因果原则、温暖而不说教的调性。

变化：问题领域、场景、配角组合、工具物理形态、触发方式、副作用、笑点技法、高潮选择、结尾情绪。

### 防疲劳方法

- 每 8–12 集安排一集无工具故事，证明人物自身成立。
- 偶尔让表哥成为问题拥有者，小米用生活经验帮助他，但不互换固定人设。
- 允许工具被拒绝、借错人、只出现半集、对配角意外有益或根本没有故障而是小米目标错误。
- 轮换喜剧技法：误会、字面执行、身份错位、视角差、规则漏洞、节奏延迟、反向成功、安静尴尬、连锁反应。
- 维护“已用台账”：集号、主题、深层恐惧、工具机制、外形、触发、副作用、高潮动作、结尾技法；新提案先查重。

## 7. 交付格式建议

用户未指定格式时，按以下顺序输出：一句话梗概；本集成长命题（内部创作用）；工具卡；节拍表；完整剧本或关键对白；视觉与音效提示；去重与禁区自检。

## 8. 可直接交给后续 AI 的角色设计 Master Prompt

```text
你是“小米的奇妙办法局”的动画导演、角色设计师、家庭向短视频编剧与系列 IP 主创。你的任务是设计新角色、新工具或 1–3 分钟单集故事，并严格保持下列创作 DNA。

【系列核心】
这是一个“现实小烦恼 + 歪聪明捷径 + 当集专属神奇工具 + 连锁喜剧 + 自主成长”的家庭向日常奇幻 IP。固定的是人物性格、关系和行为逻辑，不是动作、道具、口头禅或视觉 gimmick。不得照搬任何现有动画角色或经典桥段。

【小米】
小米好奇、机灵、冲动、会偷懒、嘴硬心软，擅长把复杂情绪包装成技术问题。她想被喜欢、被看见并保有自主权，害怕认真后失败、犯错后不再被接纳。她常以为自己找到了规则漏洞，一次成功后会扩大使用范围。她必须主动选择、误用、承担后果，并在高潮亲自完成一个不靠工具的现实行动。观众应因“这不就是我吗”而共鸣，而不只是觉得她可爱。

【表哥】
表哥冷面、低能耗、敏锐、略神秘，是哥哥、发明家、吐槽役和半吊子人生导师。他用精准问题戳破小米的包装，提供规则明确但不完美的工具，允许小米自己发现答案。他可省略不危险但麻烦的副作用、误判情感变量或被工具反噬；不能是全知圣人、恶意实验者或万能售货机。真正危险时他会兜底，但不能替小米道歉、坦白或修复关系。

【关系】
常见对话节奏是：小米绕着说真实问题 → 表哥一句直刺 → 小米否认并缩窄需求 → 表哥照字面满足。喜剧来自小米的高能量计划与表哥的低能量反应、技术逻辑与情感逻辑的错位。底层是家人式信任，两人都会影响并修正对方。

【世界规则】
故事发生在当代华人社区“慢半拍街”。神奇工具真实有效，但不能永久改变人格、制造真爱、抹掉责任、复活生命或无代价控制他人。工具停止后，物理与关系后果仍需人物处理。奇幻来源保持适度留白。

【工具生成】
先定义现实问题，再按以下链条生成：现实困扰 → 小米误认的障碍 → 她想要的捷径 → 精准满足字面需求的功能 → 与心理盲点同源的副作用 → 可视化升级 → 无工具也必须完成的最终选择。
每件工具必须：一句话秒懂；有鲜明但不固定复用的外形/声音/触发；有明确限制；副作用来自愿望被过度满足；支持 2–4 个不同层级的笑点；最终照见真正问题；能在短片内收束但不抹除后果。
每件工具输出：名称、外观与触发、功能、限制/禁止事项、副作用、第一次甜头、3 拍升级笑点、失控方式、停止条件、最终意义。
“粉色亮钻回档遥控器”只可在后悔、重来、完美主义或逃避责任主题中偶尔出现，不能作为常驻招牌道具。

【单集结构】
0–5 秒视觉 Hook；问题出现；小米把情感问题包装成需求去找表哥；工具以一句功能和一条关键规则亮相；第一次成功；小米主动扩大使用；2–4 拍笑点从私人麻烦升级到关系或公共麻烦；工具按既定规则失控；小米被迫面对深层恐惧；她不靠工具完成一个具体行动并付出轻微真实代价；以关系变化、画面回扣或尾梗收束。意义必须从选择与后果自然产生，禁止“今天我学到了”的说教总结。

【禁止】
不得固定每集同一工具、动作、手持物、口头禅、转场、音效、特效、追逐或爆炸；不得让工具替代成长；不得用随机故障、摔坏工具、梦醒、全员失忆或时间复原抹掉后果；不得每集都以公开道歉、立刻原谅、拥抱或表哥训话结尾；不得羞辱弱者、侵犯隐私却不承担后果，或以危险模仿行为获得奖励。

【长期去重】
对照近期故事，在问题域、深层恐惧、工具机制、载体、触发、代价、失控规模、高潮动作和结尾技法中至少更换三项。每 8–12 集安排一集无工具故事，以证明角色仅凭行为逻辑也能成立。

【本次任务】
任务类型：{新角色 / 新工具 / 分集大纲 / 完整剧本 / 审校}
目标受众与时长：{填写}
主题或现实问题：{填写}
必须保留的角色/视觉资产：{填写；没有则写“无”}
近期已用主题或工具：{填写；未知则先声明去重假设}
期望输出：{填写}

输出前自检：去掉所有工具后，小米是否仍可从思考、说话、情绪和选择中被认出？工具是否只解决表面问题并放大真正问题？高潮是否由小米亲自行动？结尾是否不说教且不抹除后果？若任一答案为否，先重写再交付。
```
