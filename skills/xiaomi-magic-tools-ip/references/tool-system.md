# 每集神奇工具生成系统

## 1. 生成公式

从问题生成工具，而不是从特效生成故事：

`现实困扰 → 小米误认的障碍 → 她想要的捷径 → 能精准满足字面需求的功能 → 与心理盲点同源的副作用 → 可视化升级 → 无工具也必须完成的最终选择`

例：不敢道歉 → 误以为障碍是“不知道对方怎么想” → 想先确认一定会被原谅 → 听见未说出口的念头 → 所有杂念都被放大且脱离语境 → 小米被信息淹没 → 她在无法保证结果时仍亲口道歉。

## 2. 工具硬规则

每件工具必须同时满足：

1. **秒懂**：功能可用一句 15–25 字的话解释。
2. **可演**：外形、声音、触发动作或反馈至少有一个强视觉点，但不成为全剧固定 gimmick。
3. **有缝隙**：明确适用范围、时限、次数、对象或字面漏洞。
4. **副作用同源**：副作用来自愿望被过度满足，不是随机爆炸。
5. **能升级**：至少支持 3 拍不同层级的笑点：私人小麻烦 → 关系误会 → 公共失控。
6. **能照心**：它使真正的恐惧可见，并在高潮失去替代作用。
7. **可收束**：1–3 分钟内能停止，且残留一个需要人物处理的后果。

建议写出一句“禁止事项”：工具不能做什么。这能防止万能能力破坏因果。

## 3. 设计维度

- 功能域：信息、时间、情绪、关系、身体感受、概率、记忆、表达、劳动、身份视角。
- 载体：贴纸、夹子、眼镜、雨伞、印章、耳机、粉笔、杯子、袜子、徽章、相机、计时器；避免连续多集同类外形。
- 触发：说出条件、触碰对象、打勾、倒计时、交换物件、完成动作；避免每次都按按钮。
- 代价：范围扩大、字面执行、延迟反弹、情绪转移、欠账累积、信息过载、效果错位、概率平衡。
- 停止条件：主动承认、归还某物、完成现实行动、让受影响者自己选择；不能总靠摔坏工具。

## 4. 20 个基准工具

这些是设计标尺与灵感库，不是固定道具库。新创作优先生成未使用的新工具；复用时必须换主题、规则或戏剧功能。

| 工具名称 | 功能 | 副作用 | 喜剧点 | 最终意义 |
|---|---|---|---|---|
| 真心字幕夹 | 给一个人的未说出口念头加实时字幕 | 把转瞬即逝的杂念也当成“真心”，且字幕缺少语境 | 正经谈话上方飘出“晚饭吃啥”；小米追问每句杂念 | 理解别人靠倾听，不靠偷看瞬间念头 |
| 三秒勇气糖 | 含下后获得三秒无畏 | 勇气消失后，未完成的话会以夸张音量继续说完 | 小米冲去道歉却把开场白喊遍全楼 | 勇敢不是不害怕，而是害怕时仍把话说完 |
| 明天再做钟 | 把一件任务推迟到明天 | 被推迟的任务会在明天复制一份“利息” | 一页作业变两页，整理袜子变成袜山 | 拖延不会消灭任务，只会挤走未来的时间 |
| 人见人爱徽章 | 让附近的人短暂赞同佩戴者 | 赞同没有分寸，所有人争着替她决定和帮忙 | 同学抢着背书包、选午餐，关心变围堵 | 被喜欢不等于被了解，边界比讨好重要 |
| 后悔回档遥控器 | 回到一个短暂选择点，可采用粉色亮钻外观 | 只回时间，不回记忆与疲劳；重复越多细节越偏 | 小米背熟对话却被对方一句新话打乱 | 重来不能保证完美，承担才让事情继续 |
| 半页未来票 | 显示未来某一幕的半张画面 | 关键上下文永远在另一半 | “奖杯”其实是蛋糕装饰，“哭脸”是切洋葱 | 知道结果碎片不等于理解未来 |
| 情绪同声耳机 | 把语气背后的情绪翻成词语 | 混合情绪会同时播报，声音互相打架 | “生气、担心、饿、想面子”四声道齐播 | 人可以同时有多种感受，不能贴单一标签 |
| 自动完成手套 | 自动完成佩戴者说出的任务 | 按最省力的字面标准完成 | “收好房间”把所有东西塞进同一只柜子 | 完成不等于负责，过程里有判断和心意 |
| 借口盖章机 | 给借口盖章后让人暂时相信 | 每用一次，借口会实体化成越来越大的纸条黏住使用者 | 小米顶着“堵车”“猫吃了作业”的纸条寸步难行 | 借口能推迟尴尬，不能搬走责任 |
| 完美滤镜镜 | 让镜中一切呈现理想版本 | 离镜越远现实反差越明显，使用者开始只对镜行动 | 小米边走边举镜，避开真实的乱桌和朋友 | 接受不完美，才有空间真正改善 |
| 轮到我扩音扣 | 保证佩戴者在谈话中获得发言机会 | 每次插话都会把音量加倍，且无法跳过别人被打断的句子回声 | 小米一句“听我说”后，所有被打断的话排队回放 | 表达自己与听完别人是同一件事 |
| 比较尺 | 把两个人的表现量化显示 | 指标随测量者在意的事变化，没有总分 | 小米在速度上赢，耐心分却负数，尺子疯狂换单位 | 比较没有终点，成长要看自己的方向 |
| 秘密保鲜盒 | 把秘密放入盒中后无法说出口 | 与秘密相关的普通词也会被冻结成冰块 | 小米想说“今天学校……”嘴里掉出冰块 | 保密不等于独自承受，可信任的大人是出口 |
| 注意力磁铁 | 把所有人的注意力吸到佩戴者身上 | 注意力包含挑错、询问和围观，无法只吸引赞美 | 小米表演一半，连路人都来纠正鞋带 | 被看见有代价，自我价值不靠全场注视 |
| 五分钟交换鞋 | 让两人交换五分钟的身体感受与处境 | 只交换感受，不交换记忆，双方会误判原因 | 小米以为朋友生气，其实是新鞋磨脚又紧张 | 换位是理解的开始，不是替别人下结论 |
| 好心加速喷雾 | 让“帮忙”的动作快十倍 | 快而不问需求，帮助会越帮越忙 | 浇花变水灾、收桌把未吃完的饭也收走 | 真正帮助要先问对方需要什么 |
| 输赢转换骰 | 输掉小游戏时可交换一次结果 | 被交换的“失落感”不会消失，而会随机落到旁人身上 | 小米赢了却发现全场莫名替她委屈 | 赢不是把难受丢给别人，输也能被承受 |
| 记忆便利贴 | 贴在物品上就能回放与它有关的记忆 | 回放从每个人视角不同，且会串台 | 同一块蛋糕被三个人记成“最后一块” | 记忆不等于录像，关系需要核对而非审判 |
| 反话翻面伞 | 把伞下的反话自动翻成真实意思 | 玩笑、客套和未想清的感受也被强制直说 | “随便”变成超长菜单要求，“没事”喷出一串小抱怨 | 真诚需要时机、分寸和自己开口 |
| 安静泡泡机 | 给使用者制造绝对不受打扰的泡泡 | 泡泡也隔绝求助、提醒和回应，且越逃避越厚 | 小米享受清净，后来拼命打手势想加入游戏 | 边界不是隔绝，独处后仍要回到关系里 |

## 5. “粉色亮钻回档遥控器”的重新定位

它是“后悔回档遥控器”的一种具体外观，可在关于后悔、完美主义、逃避责任、害怕选错的单集中出现。亮钻与粉色可体现小米把“重来”想象得轻松漂亮，随后与不断累积的疲惫和偏差形成反差。它不得承担角色 Logo、常驻随身物、每集转场按钮或万能修复功能。

## 6. 工具去重检查

对照最近 10 集，至少有 3 项不同才算新工具：功能域、载体、触发方式、代价机制、视觉反馈、失控规模、停止条件、揭示的心理问题。只换名字和外壳不算新工具。

避免连续使用：读心/预测类、按钮类、时间类、让全体 NPC 同一种反应、追逐收尾、物体无限复制、工具摔坏恢复原状。
